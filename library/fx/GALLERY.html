A hand-drawn arrow draws itself from a point to a target element, with an optional label; use it to tell the viewer where to look.

  • FX.arrowAnnotate(H, root, {at, dur = 0.8, from: {x, y}, target: el|selector, to: {x, y}, label, labelSize = 44, color: 'accent', strokeWidth = 6, headSize = 38, bow = 0.25, gap = 24, sketch = true, seed = 3, exitAt, exitDur = 0.25}): the arrow is added to root; points are stage px inside root
  • returns {svg, from, to}

Callout

fx:callout

A label box lands next to one spot, then a line draws from the box to that spot; use it to name a part of the picture.

  • FX.callout(H, root, {at, label = 'Look here', target: el|selector, x, y, position = 'top-right'|'top-left'|'bottom-right'|'bottom-left', offset = 170, size = 52, color: 'accent', lineWidth = 5, dur = 0.5, lineDelay = 0.3, lineDur = 0.5, margin = 60, gap = 20, exitAt, exitDur = 0.25}): box and line are added to root; x, y and the target are stage px inside root
  • returns {el: box, svg, anchor}

Camera shake

fx:camera-shake

One short shake of the whole scene that fades to rest by itself; use it for an impact, a hit or a slam, not as idle motion.

  • FX.cameraShake(H, el, {at, dur = 0.6, intensity = 14, rotate = 0.5, rate = 20, decay = 2, seed = 1}): el shakes from `at` for `dur` seconds and then sits still
  • returns {el, at, end}
