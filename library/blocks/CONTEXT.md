# library/blocks: reusable HyperFrames scene parts

Ready-made parts for HyperFrames scenes (chat screen, cursor, stamp, phone, browser ...), so a new video starts from parts that already passed a review.

**Reads:** `<id>/block.md` (frontmatter: id, title, description, tags, files, depends, api, preview_at), `<id>/<id>.js|css`, `<id>/demo.html` (runs standalone with `_demo/cues.js`).
**Does:**
- Find: `python anim.py lib find <words>` matches id, title, tags and description. The index is `library/INDEX.json` (generated by `lib index`, never edited by hand).
- Look: `python anim.py lib gallery` renders `<id>/preview.png` from each demo and writes `GALLERY.html` (studio: `http://127.0.0.1:8765/library/blocks/GALLERY.html`).
- Use: `python anim.py use <slug> block:<id>` copies the block and its `depends` into `videos/<brand>/<slug>/04_scene/blocks/`, logs it in `assets/library.md` and prints the `<link>`/`<script>` lines (after `runtime/hf-bridge.js`).
**Writes:** nothing in videos by itself; `use` writes the copies. A video keeps its own copy, so a later change here never alters an old video.
**Human check:** you approve a new block together with the video it came from.

## Rules for a block
- Colours and fonts only through `var(--ink|--accent|--cream|--dim|--line|--green|--font|--head)`; it takes the brand of the video.
- Class names start with `b-`; no ids, so two copies of a block work in one scene.
- Every motion is a tween on the paused timeline (`H.tl`), placed at a time the caller gives (a cue or a word time).
- No logos or brand names of other companies. Record a rebuilt app screen as rebuilt in `REVIEW.md`; never label it on screen (`_shared/tone.md`).
- Never assign a media source or volume in script (the render's audio check refuses it).

## Adding a block
1. After a video, note reusable parts in that video's `REVIEW.md`. Add them only after you approve the video.
2. Copy `_templates/block/` to `library/blocks/<id>/`, move the code out of the scene, give it an API on `H` (`core`), and a demo.
3. `python anim.py lib index`, then `lib gallery`, and run `tests/test_blocks.py` and `tests/test_blocks_browser.py`.
