# Sound sources

Every file in this folder is CC0 1.0 (public domain dedication). No credit is needed. The credit is given here anyway.
Each file was converted: effects are mono 44.1 kHz OGG Vorbis (quality 4), silence trimmed, peak about -6 dBFS.
Music is stereo 44.1 kHz OGG Vorbis (quality 4), set to about -16 LUFS.
