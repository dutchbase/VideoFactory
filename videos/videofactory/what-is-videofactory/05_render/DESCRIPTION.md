## Description

VideoFactory is a free, open-source workspace that turns one conversation with your AI agent into a finished explainer video. It is one folder on your computer. Claude Code or Codex does the work, and you check every step: brief, script, voice, words, cues, scene and render. Nothing paid or public happens without a clear yes from you.

This video was made with the same commands it shows.

Get it: https://github.com/dutchbase/videofactory. Clone the repo and type `/vf-setup`.
