# Script production

Follow the current session and named-scope rules in [`permissions.md`](permissions.md). Human review and permission to complete a stage are separate.

This is the production contract for a script. It is local: nothing outside this repo is needed to write or review a script.

## Inputs

Read the video's `project.json`, its frozen `settings.json`, the selected `brands/<brand>/brand.md`, the brand's voice guidance and `_shared/tone.md`. Load relevant verified lessons for this brand and stage. Use supplied evidence or the numbered sources in `00_research/research.md` for factual claims.

## Direction and brief

1. Save the audience, purpose, language and intended result in `01_voice/brief.md`.
2. List the evidence and any claims that still need evidence.
3. Write three different opening angles.
4. Select an opening and a story structure. Explain the choice in one sentence.
5. List the beats, the final payoff and the essential pictures.
6. Answer part A of `_shared/plan-check.md`.
7. If the brand sets a quality bar, add a numbered scene list: the first 1 to 2 second hook, a visual change every 3 to 5 seconds, motion assets and a sound plan.
8. Complete the brief gate under the current permission. Full permission may accept a ready brief after checks; review-each-stage and selected-stage modes pause for the required human decision.

Record stage completion with `--accept` only when the current permission allows it. Use a fingerprinted human decision when the permission requires review or the user asks for a decision. See `_shared/permissions.md` and `_shared/autonomous-runs.md`.

## Draft and critique

1. Save the first draft as `01_voice/draft-original.md`.
2. Save the canonical script as `01_voice/script.md`. Put the spoken words in the first fenced block. Put scene cues and production notes outside that block. Write for the ear: `_shared/voice.md`.
3. Ask a separate reviewer to write `01_voice/critique.md`. Each finding names the passage, the effect on the audience and a specific correction.
4. Make up to two script revisions. Record unresolved findings for review.
5. Check facts, meaning, names, pronunciation, pace, brand fit and permissions.
6. Complete the script gate under the current permission before voice work. Paid voice generation always needs separate approval for the exact managed request and its known cost. Follow `_shared/autonomous-runs.md`; stop if the cost cannot be quoted.

Never invent prices, results, course content, testimonials or quotations. Another brand's claims do not become this brand's evidence.
