# Library and stock

Reusable assets for any scene. Shelf: `library/` (committed, small). Stock video and photos are downloaded on demand into `library/cache/` (git-ignored). Run commands as `.venv/bin/python anim.py ...`.

First read `library/CATALOG.md`: every kind and category with counts, examples and the command to use it (generated by `lib index`).

## Which one?
| Need | Do |
|---|---|
| An animated part for either engine (text effect, entrance, background, chart, interface) | `lib find <words> --kind fx --brand <brand>`, then `use <slug> fx:<id>`; it prints the lines for the video's engine (`library/fx/CONTEXT.md`) |
| An icon that draws or moves | `lib find <word> --kind animicon --brand <brand>`, then `use <slug> animicon:lucide-animated/<name>` |
| A look nothing on the shelf gives | `lib find <words> --kind upstream --brand <brand>` lists components we can rewrite; `lib port upstream:<source>/<name> --slug <slug>` (`porting.md`) |
| A symbol in the text colour | `lib find <word> --brand <brand>`, then `<i data-icon="rocket"></i>` in the scene (`_shared/modern.md`) |
| An icon file from a larger set | `use <slug> icon:lucide/rocket` copies the SVG to `04_scene/assets/icons/lucide/rocket.svg`; show it with `<img>` |
| A colour pictogram | `use <slug> graphic:fluent-emoji-flat/rocket`, then `<img src="assets/graphics/fluent-emoji-flat/rocket.svg">` |
| Motion graphic | `lib lottie add <json-url> --license CC0-1.0 --license-ok`, `use <slug> lottie:name`; in `scene.js`: `const c = Lib.lottie('name'); c.at(ctx, t, x, y, w, h, { loop: true })` (HyperFrames: inside `H.drive`; `use` prints the lines) |
| SVG shape morph | `const m = Lib.svgMorph(fromD, toD, { shapeIndex: 'auto', map: 'size' });` then `ctx.fill(m.path(P.prog('cue')), 'evenodd')` |
| Real-world footage or a photo | `stock search`, then `use` |
| A new icon not on the shelf | `lib icon add set/name` (sets: `library/sources.json`) |
| A ready-made motion clip (device, AI moment, counter, background) | `lib find "<words>" --brand <brand>`, then `use <slug> motion:<brand>/<ID> [--as name] [--start s --end s]`: it renders the clip in the video's format and makes 24 fps frames. Play it with `Modern.clip` (`modern.md`). Overlays need transparency and do not work as clips. |
| A ready-made HyperFrames part (chat screen, cursor, stamp, phone, browser) | `lib find <words> --brand <brand>`, then `use <slug> block:<id>` (see Scene blocks) |
| A sound effect or a music track | `audio find "<words>"`, then `use <slug> audio:<id>` (`library/audio/CONTEXT.md`) |
| A steps file to record a real tool (ChatGPT, Claude) | `lib find chat --brand <brand>`, then copy `library/captures/<name>.steps.txt` (`capture.md`) |

Load `<script src="runtime/lib.js"></script>` after `runtime/player.js` for every `Lib.*` call. `ctx` is a 2D canvas context: add a `<canvas>` to the shot, call `canvas.getContext('2d')` and draw into it from `P.onFrame`. Call `Lib.*` loaders at the top of `scene.js`, so rendering waits for the files. `lib gallery` writes contact sheets of every icon and graphic to `_shared/gallery/library-icons.png` and `library-graphics.png`.

`Lib.svgMorph` takes SVG path `d` strings (including paths with several contours). Its `.ready` promise prepares the morph once. `P.wait` also tracks it automatically. After readiness, `.path(progress)` returns a `Path2D` for any progress from 0 to 1. Pass that to `ctx.fill` or `ctx.stroke`. Use the `evenodd` fill rule when the path contains holes. The original shapes are returned exactly at progress 0 and 1. `shapeIndex` and `map` use [MorphSVG's public options](https://gsap.com/docs/v3/Plugins/MorphSVGPlugin/). `map` accepts `size`, `position` or `complexity`. The engine loads locally only when a morph is requested. Invalid path data or a missing engine rejects `.ready` and the render asset wait.

`Lib.lottie(name)` loads its local renderer and generated data wrapper. The clip becomes ready only on the renderer's `DOMLoaded` event. A missing file, a renderer error or a 30-second initialization timeout rejects `clip.whenReady` and the render asset wait. `.at(ctx, t, x, y, w, h, {loop, alpha})` can then be called at any time, including out of order. `Lib.lottie(name, { colors: 'brand' })` recolours a copy of the data with `window.BrandTokens` (greys to ink/dim/faint/surface by lightness, other colours to the nearest of accent, accent2, green, danger). The file on disk stays unchanged. To look at every animation in both colour sets, open `library/lottie/GALLERY.html` (made by `tools/lottie_sheet.py`).

For each **new** Lottie import, read the asset's own licence page. Give its exact allowlisted licence with `--license`, plus `--license-ok` to confirm the check. For a LottieFiles asset under its Simple License, use `--license Lottie-Simple`. Existing library entries keep their recorded rights. The importer does not relabel them. GSAP files and their custom licence are recorded in [`_runtime/vendor/GSAP-NOTICE.md`](../_runtime/vendor/GSAP-NOTICE.md).

## Stock
```
stock search pexels|pixabay|unsplash|all "remote work" --type video --slug <slug>
stock get stock:pexels/video/123
use <slug> stock:pexels/video/123 --as bg --start 0 --end 5     # video: becomes frames in assets/bg/; play with Modern.clip (modern.md)
use <slug> stock:unsplash/photo/abc --as cafe                   # photo: assets/cafe.jpg, show with <img>
```
- `--slug` sets portrait for a 9:16 video, else landscape. Unsplash has photos only.
- Video is cut to 12 frames a second at 1280 wide. Keep clips short. In a HyperFrames video, `use` makes a silent `assets/<name>.mp4` instead. Show it with `<video class="clip" src="assets/<name>.mp4">`.
- Keys in `.env`: `PEXELS_API_KEY`, `PIXABAY_API_KEY`, `UNSPLASH_ACCESS_KEY` (see `START-HERE.md`). Search results are cached 24 hours.

## Music
```
stock search openverse "calm piano" --type audio               # CC0 only, no key, tracks of 30 s or more
use <slug> stock:openverse/audio/<id>                          # assets/music-openverse-<id>.mp3
```
Then put `music: file:music-openverse-<id>.mp3 0.2` before the first cue in `03_cues/cues.md`, run `cues`, then `render`. The track loops or is cut to the video and fades out in the last 2 seconds. Listen first. Results are mixed (loops, sound effects, long ambience), so a person picks the track. The sound library has hundreds of CC0 tracks with categories (`library/audio/INDEX.md`): `audio find "<words>" --kind music`, then `use <slug> audio:<id> --as <name>`. Mixkit forbids scripts: download a track by hand into `library/audio/inbox/mixkit-music/`, then `audio fetch`. Pixabay music has no API: download by hand, copy the file into `04_scene/assets/` and log it in `assets/sound.md`.

Sound effects, levels and loudness: `sound.md`.

## Scene blocks (HyperFrames)
Reusable scene parts live in `library/blocks/<id>/` (`block.md` describes the API, `demo.html` shows it). Find one with `lib find <words> --brand <brand>` (matches id, title, tags and description). To browse them, run `lib gallery`, then open `http://127.0.0.1:8765/library/blocks/GALLERY.html` while Studio runs. `use <slug> block:<id>` copies the block and its dependencies into `04_scene/blocks/` and prints the `<link>` and `<script>` lines. How blocks are made and added: `library/blocks/CONTEXT.md`.

## Rules
- Allowed pictures: stock video and photos (Pexels, Pixabay, Unsplash), Openverse CC0, images made with AI (route: `image-generation.md`) and your own screen recordings (`capture.md`). Put any AI disclosure your platform needs in the description, not on screen.
- Only licences on the allowlist (`libcore.ALLOWED`). Nothing that needs attribution.
- `use` logs every item in `videos/<brand>/<slug>/04_scene/assets/library.md`. Copy credits (photographer, source) into `05_render/DESCRIPTION.md`.
- Never show stock people as your customers, staff or endorsers. If a viewer could mistake them for real people of the brand, do not use the shot. Never put provenance labels such as "illustrative" or "stock footage" on screen (`tone.md`).
- Check the licence line `use` prints. Look at the contact sheet before you choose.
- Do not edit `library/INDEX.json` (made by `lib index`) or the `*.js` next to a Lottie file (generated).

## Brand libraries and adaptation

Search the selected brand's `brands/<brand>/library/` first, then the shared `library/`. Use `lib find <words> --brand <brand>`.

Use an asset from another brand only with an explicit source selection (`lib adapt`). Keep the source, rights, source hash, target brand, changes and resulting asset hash. Apply target tokens only to assets designed for token replacement. Recreate baked styling, logos, characters and screenshots, or supply a suitable replacement. Verify target-brand styling and claims before you use it. New reusable results stay draft until you decide. Never transfer another brand's identity, testimonials or factual claims.
